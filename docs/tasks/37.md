# Future / V2 - Gamification Progression Model

Create a progression layer for avatar, XP, level, badge, and achievement systems.

Flow:

1. Learner completes feedback activity.
2. System awards XP and progression updates.
3. Learner profile reflects the new level and badges.
4. Progress stays aligned with consistent participation.

Create:

Data Models:
- LearnerProgress
- Badge
- Achievement
- ExperienceTransaction

TypeScript interfaces:

LearnerProgress:
- learnerId
- xp
- level
- avatarId
- updatedAt

Badge:
- id
- name
- description
- icon

Achievement:
- id
- name
- requirement
- unlockedAt

ExperienceTransaction:
- id
- learnerId
- source
- xp
- createdAt

Requirements:

- Add a progression model on top of the point system.
- Support avatars, XP, levels, badges, and achievements.
- Keep the rules separate from feedback scoring.
- Prepare the data structure for future profile UI.
- Keep the system focused on consistency rather than speed.

Constraints:

- Future / V2 only.
- Frontend first.
- No effect on current MVP scoring rules.
- No backend implementation yet.
