# MVP - Mentor Coverage and Useful Feedback Metrics

Create mentor-facing coverage metrics so the team can see who has submitted feedback and whether the responses are useful for insight.

Flow:

1. Mentor opens the dashboard.
2. System shows completion coverage by class.
3. System highlights useful feedback counts.
4. Mentor sees only aggregated and anonymous information.

Create:

Data Models:
- FeedbackCoverage
- UsefulFeedbackSignal
- MentorDashboardSummary

TypeScript interfaces:

FeedbackCoverage:
- classId
- totalLearners
- completedCount
- pendingCount
- coveragePercent

UsefulFeedbackSignal:
- classId
- insightCount
- feedbackCount
- updatedAt

MentorDashboardSummary:
- classId
- coveragePercent
- usefulFeedbackCount
- lastUpdatedAt

Architecture:

UI
↓
Dashboard Hooks
↓
Insight Service
↓
Mock/Supabase-ready Aggregation

Requirements:

- Show sudah / belum mengisi status per class.
- Show feedback coverage as a percentage.
- Surface useful feedback counts for mentor review.
- Keep learner identity hidden in all mentor views.
- Reuse the existing insight dashboard instead of creating a separate mental model.

Constraints:

- MVP only.
- Frontend first.
- Aggregation only, no raw identity exposure.
- No AI dependency.
