Create End-to-End Feedback Flow Integration.

Goal:
Connect learner feedback flow and mentor insight dashboard into one complete experience.

Flow:

Learner:
1. Enter class code
2. Join class
3. Complete anonymous feedback
4. Submit feedback
5. Feedback stored through FeedbackService

Mentor:
1. Open class dashboard
2. View received feedback
3. View insight summary


Create:

Data Models:
- FeedbackFlowState
- ClassContext

TypeScript interfaces:

FeedbackFlowState:
- currentStep
- classId
- feedbackResponse
- submittedAt

ClassContext:
- classId
- className
- mentorId


Architecture:

Learner Flow
↓
Feedback Hooks
↓
FeedbackService
↓
Mock Storage
↓
Insight Service
↓
Mentor Dashboard


Requirements:

- Connect Join Class flow with feedback submission.
- Pass selected class information through feedback flow.
- Store feedback using FeedbackService abstraction.
- Update mentor dashboard from submitted feedback.
- Create shared mock data layer.
- Ensure learner remains anonymous.
- Add loading and empty states.
- Keep architecture ready for Supabase migration.


Constraints:

- Frontend only.
- No database.
- No authentication.
- No API calls.
- No AI integration.
- No unnecessary dependencies.
- Use mock implementation only.
