
## 8. Langkah berikutnya

Setelah koneksi berhasil, tahapan berikutnya adalah:

1. mengganti mock service dengan service berbasis Supabase
2. menghubungkan pembuatan kelas ke `classes`
3. menghubungkan submit feedback ke `feedback_responses`
4. menghubungkan dashboard insight ke query data Supabase
