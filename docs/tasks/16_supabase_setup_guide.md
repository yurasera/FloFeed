# Supabase Setup Guide for FloFeed

## Tujuan

Panduan ini memuat langkah awal untuk menyiapkan Supabase untuk proyek FloFeed, mulai dari pembuatan project, pembuatan tabel, hingga langkah koneksi awal ke frontend.

## 1. Buat akun Supabase

1. Buka https://supabase.com.
2. Daftar atau masuk menggunakan akun GitHub/Google.
3. Pilih tombol New Project.
4. Isi nama project, password database, dan region.
5. Tunggu hingga project selesai dibuat.
