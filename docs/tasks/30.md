# MVP - Feedback Completion Status

Create a status layer that shows whether a learner has already filled feedback for a class, while keeping the mentor view anonymous.

Flow:

1. Learner joins a class.
2. System checks whether feedback has been submitted.
3. Mentor sees completed and pending counts per class.
4. Learner can see pending status for their own class list.

Create:

Data Models:
- FeedbackCompletion
- ClassRoster
- CompletionSummary

TypeScript interfaces:

FeedbackCompletion:
- learnerId
- classId
- submittedAt
- status

ClassRoster:
- classId
- learnerCount
- completedCount
- pendingCount

CompletionSummary:
- classId
- coveragePercent
- completedCount
- pendingCount

Architecture:

UI
↓
Completion Hooks
↓
Feedback Service
↓
Mock/Supabase-ready Data Models

Requirements:

- Track whether feedback has been submitted per learner and class.
- Show sudah / belum mengisi status for class coverage.
- Keep learner identity hidden from mentor feedback content.
- Reuse the existing mentor dashboard structure.
- Prepare data for reminder and engagement features later.

Constraints:

- MVP only.
- Frontend first.
- No identity leakage to mentors.
- No backend implementation yet.
