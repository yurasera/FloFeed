# Future / V2 - AI Summary for Mentor Insights

Create an AI-assisted summary layer that turns anonymous feedback data into concise mentor insights.

Flow:

1. Mentor opens a class insight view.
2. System aggregates feedback responses.
3. AI produces a short summary of trends and concerns.
4. Mentor reads the summary alongside raw statistics.

Create:

Data Models:
- AIInsightSummary
- InsightPrompt
- InsightSource

TypeScript interfaces:

AIInsightSummary:
- classId
- summary
- keyTrends
- suggestions
- generatedAt

InsightPrompt:
- classId
- prompt
- context

InsightSource:
- feedbackId
- classId
- category

Requirements:

- Generate concise summaries from anonymous feedback.
- Keep the summary separate from raw metrics.
- Show the AI output as an enhancement, not as the only source of truth.
- Preserve the anonymity rules used by the mentor dashboard.
- Prepare the interface for future OpenAI or Gemini integration.

Constraints:

- Future / V2 only.
- No AI implementation yet.
- No learner identity exposure.
- No backend dependency in this task.
