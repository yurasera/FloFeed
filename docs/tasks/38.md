# Future / V2 - Streak UI and Rewards

Create a visible streak and reward experience so learners can see their consistency and earned rewards.

Flow:

1. Learner submits feedback across multiple days.
2. System tracks streak continuity.
3. Reward milestones are unlocked.
4. Learner sees progress in a dedicated UI.

Create:

Data Models:
- StreakRecord
- RewardItem
- RewardHistory

TypeScript interfaces:

StreakRecord:
- learnerId
- currentStreak
- bestStreak
- lastActiveAt

RewardItem:
- id
- name
- description
- pointsRequired

RewardHistory:
- id
- learnerId
- rewardId
- unlockedAt

Requirements:

- Show current streak and best streak.
- Show unlocked rewards and upcoming milestones.
- Keep the UI motivating but not competitive.
- Reuse the point and progression data already defined in MVP and V2 tasks.
- Prepare room for future badge or reward claim flows.

Constraints:

- Future / V2 only.
- Frontend first.
- No change to MVP submission flow.
- No backend implementation yet.
