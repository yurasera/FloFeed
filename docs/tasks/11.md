Create mentor class management prototype.

Goal:
Prepare FloFeed for mentors to manage classes before receiving anonymous feedback.

Flow:

Mentor:
1. Open mentor class management
2. View existing active classes
3. Create new class
4. Generate unique class code
5. Save class information in mock data
6. Display class ready to receive feedback

- ClassCreationForm

- isActive

Mentor:
- id
- name
- email

ClassCreationForm:
- name
- mentorId

↓
Custom Hooks

Services
↓
Data Models


Requirements:

- Create Mentor Class Management page.
- Create reusable ClassCard component.
- Create CreateClassForm component.
- Create class code generation logic using mock data.
- Store created class information in mock state.
- Display active classes created by mentor.
- Keep learner feedback flow compatible with created classes.
- Prepare interfaces for future Supabase integration.
- Prepare structure for future authentication and role-based access.


Constraints:

- Frontend only.
- No database.
- No authentication.
- No API calls.
- No unnecessary dependencies.
