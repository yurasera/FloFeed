# Future / V2 - Personalized Reflection Suggestions

Create a reflection layer that adapts prompts based on learner history, class context, and previous responses.

Flow:

1. Learner opens the reflection step.
2. System analyzes past interactions and current class context.
3. Personalized prompts are shown.
4. Learner answers with more relevant guidance.

Create:

Data Models:
- ReflectionProfile
- ReflectionSuggestion
- ReflectionRule

TypeScript interfaces:

ReflectionProfile:
- learnerId
- preferredTone
- commonStruggles
- updatedAt

ReflectionSuggestion:
- id
- classId
- mood
- prompt
- priority

ReflectionRule:
- id
- condition
- action
- enabled

Requirements:

- Adapt prompts to learner context.
- Reuse mood history and class data when generating prompts.
- Keep the reflection experience supportive and simple.
- Preserve the current prompt-based reflection flow as a fallback.
- Prepare the structure for AI-driven or rule-based prompt generation.

Constraints:

- Future / V2 only.
- Frontend first.
- No mandatory AI dependency.
- No backend implementation yet.
