Build a reusable multi-step feedback flow in React.

Steps:
1. Welcome
2. Mood
3. Reflection
4. Review
5. Success

Requirements:
- Use useState only.
- Navigation via Previous and Next buttons.
- Disable Previous on the first step.
- Disable Next on the last step.
- Prevent skipping steps.
- Progress indicator must be calculated dynamically from the total number of steps.
- Steps must come from a single array (no hardcoded conditional rendering for each step).
- Components must be reusable.
- Add smooth transitions between steps.
- Structure the code for easy scalability (adding/removing steps should only require updating the steps array).

Do not build the content of each step.
Render placeholders with the step name only.
Focus on the navigation architecture and reusable components.
