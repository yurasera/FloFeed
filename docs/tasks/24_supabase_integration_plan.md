# Supabase Integration Plan for FloFeed

## Tujuan

Dokumen ini memecah tahapan integrasi Supabase ke frontend agar lebih mudah diimplementasikan bertahap.

## Tahap 1: Setup dasar

- Buat project Supabase
- Simpan URL dan anon key
- Tambahkan environment variable
- Instal `@supabase/supabase-js`
