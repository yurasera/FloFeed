# MVP - Basic Points Engine

Create a simple point system that rewards consistency and timely feedback without judging feedback content.

Flow:

1. Learner submits feedback.
2. System calculates points from timing and feedback type.
3. Total points are stored for the learner.
4. Milestone totals are prepared for future gamification.

Create:

Data Models:
- PointTransaction
- PointsSummary
- RewardMilestone

TypeScript interfaces:

PointTransaction:
- id
- learnerId
- classId
- reason
- points
- createdAt

PointsSummary:
- learnerId
- totalPoints
- feedbackCount
- streakCount

RewardMilestone:
- id
- name
- requiredPoints
- rewardValue

Rules:

- Mengisi feedback dalam 24 jam: +10 poin.
- Mengisi feedback setelah 24 jam: +5 poin.
- Mood Check: +5 poin.
- Prompt Reflection: +10 poin.
- Feedback Lengkap: +15 poin.
- Mengisi feedback: +10 poin bonus.
- Streak 7 hari: +30 poin.
- Total 30 feedback: +100 poin.

Requirements:

- Calculate points from activity, not from feedback quality.
- Store the result as a separate transaction.
- Keep the scoring logic reusable for future rewards.
- Prepare the data model for streak and badge systems.

Constraints:

- MVP only.
- Frontend first.
- No manual point editing from the UI.
- No scoring based on sentiment or answer quality.
