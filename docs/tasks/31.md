# MVP - Feedback History and Progress

Create a learner-facing history view so users can review their own feedback activity and build a habit over time.

Flow:

1. Learner opens feedback history.
2. System shows past submissions by class.
3. Learner reviews mood, timestamp, and point totals.
4. Learner sees a simple progress summary.

Create:

Data Models:
- FeedbackHistoryEntry
- LearnerProgressSummary

TypeScript interfaces:

FeedbackHistoryEntry:
- id
- classId
- selectedMood
- createdAt
- pointsEarned

LearnerProgressSummary:
- learnerId
- totalFeedback
- totalPoints
- lastSubmittedAt

Architecture:

UI
↓
History Hooks
↓
Feedback Service
↓
Mock/Supabase-ready Data Models

Requirements:

- Display a chronological list of past feedback submissions.
- Show class name, mood, and submission time.
- Show learner progress at a glance.
- Keep history private to the logged-in learner.
- Keep the mentor dashboard focused on aggregated data only.

Constraints:

- MVP only.
- Frontend first.
- No duplicate feedback entry creation.
- No identity exposure to mentors.
