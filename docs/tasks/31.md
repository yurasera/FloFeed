# MVP - Basic Points Engine

## Goal

Create a simple points system that rewards consistency and timely feedback submission without evaluating the quality or sentiment of learner responses.

## Flow

Learner:

1. Submit feedback.
2. System calculates earned points based on submission timing and completed feedback activities.
3. System records each earned point as a transaction.
4. System updates the learner's points summary.
5. Milestone data is prepared for future gamification features.

- Calculate earned points from completed feedback activities.
- Return a list of point transactions.

- Store earned points as a separate transaction.

- Calculate learner point statistics.

- Return available reward milestones.

## Scoring Rules

- Submit feedback within 24 hours: **+10 points**
- Submit feedback after 24 hours: **+5 points**
- Complete Mood Check: **+5 points**
- Complete Prompt Reflection: **+10 points**
- Complete Full Feedback: **+15 points**
- Feedback submission bonus: **+10 points**
- 7-day submission streak: **+30 points**
- Complete 30 feedback submissions: **+100 points**

---

## Requirements

- Create a reusable points calculation engine.
- Calculate points based on learner activities only.
- Do not calculate points based on feedback quality or sentiment.
- Store every earned point as an individual transaction.
- Display learner points summary.
- Track total earned points.
- Track total feedback submissions.
- Track current streak count.
- Keep scoring logic reusable for future reward systems.
- Prepare data models for future streak, badge, and achievement features.
- Use mock data.
- Create reusable points-related components.
- Keep compatible with the existing feedback flow.

---

## Constraints

- MVP only.
- Frontend only.
- No backend.
- No database.
- No API calls.
- No external services.
- No manual point editing from the UI.
- No scoring based on sentiment or answer quality.
- Use mock data only.
- Do not change the existing feedback submission flow.
