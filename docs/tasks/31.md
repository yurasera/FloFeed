# MVP - Feedback History and Progress

## Goal

Provide learners with a private history view so they can review past feedback submissions, track participation, and build a consistent reflection habit over time.

## Flow

Learner:

1. Open feedback history.
2. View previous feedback submissions.
3. Review class, mood, submission time, and earned points.
4. View personal progress summary.

## Requirements

- Create Feedback History page.
- Display learner feedback history in chronological order.
- Display class name, selected mood, submission time, and earned points.
- Display learner progress summary.
- Show total feedback submitted.
- Show total points earned.
- Show latest submission date.
- Show empty state when no history exists.
- Keep history visible only to the logged-in learner.
- Keep mentor dashboard focused on aggregated anonymous data only.
- Use mock feedback data.
- Create reusable history and summary components.
- Create responsive layout.
- Keep compatible with `FeedbackService` from previous tasks.
- Prepare architecture for future achievement, streak, and progress features.

---

## Constraints

- Frontend only.
- No backend.
- No database.
- No authentication changes.
- No API calls.
- No external services.
- No duplicate feedback history entries.
- Use mock data only.
- Do not change existing feedback flow.
