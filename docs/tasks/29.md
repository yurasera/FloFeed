# MVP - Learner Registration and Login

Create learner access so the system can track participation without exposing identity to mentors.

Flow:

1. Learner registers or logs in.
2. System persists the learner session.
3. Learner can continue into the feedback flow.

Create:

Data Models:
- Learner
- LearnerSession
- LearnerMembership

TypeScript interfaces:

Learner:
- id
- name
- email
- createdAt

LearnerSession:
- learnerId
- isAuthenticated
- lastActiveAt

LearnerMembership:
- learnerId
- classId
- joinedAt
- isActive

Architecture:

UI
↓
Auth Hooks
↓
Auth Service
↓
Mock/Supabase-ready Data Models

Requirements:

- Add learner register and login screens.
- Persist authenticated state across refresh.
- Keep learner identity separate from feedback visibility.
- Prepare the structure for future Supabase Auth integration.
- Keep the current anonymous feedback flow unchanged.

Constraints:

- MVP only.
- Frontend first.
- No mentor-facing identity exposure.
- No unnecessary dependencies.
