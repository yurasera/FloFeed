Create Mentor Insight Dashboard.

Goal:
Provide mentors with a way to understand learner feedback patterns before adding AI-powered insights in the future.

Flow:

Mentor:
1. Open insight dashboard
2. Select class
3. View feedback summary
4. Analyze learner mood trends
5. Identify common struggles from anonymous feedback


Create:

Data Models:
- FeedbackInsight
- MoodDistribution
- ReflectionSummary

TypeScript interfaces:

FeedbackInsight:
- classId
- totalFeedback
- moodDistribution
- commonStruggles
- reflectionSummary
- generatedAt

MoodDistribution:
- mood
- count
- percentage

ReflectionSummary:
- category
- summary
- frequency


Architecture:

UI
↓
Dashboard Components
↓
Custom Hooks
↓
Insight Service
↓
Mock Data


Create:

Reusable Components:
- InsightCard
- MoodChart
- StruggleList
- ReflectionSummaryCard

Insight Service:

Functions:

- getFeedbackInsight()
  - Retrieve processed feedback insight data
  - Return dashboard-ready data

- getMoodDistribution()
  - Calculate mood distribution from feedback data

- getCommonStruggles()
  - Extract common learner struggles from reflection answers


Requirements:

- Create Mentor Insight Dashboard page.
- Display total feedback received.
- Display mood distribution visualization.
- Display common learner struggles.
- Display reflection summary.
- Use mock feedback data.
- Use reusable card and chart components.
- Create responsive dashboard layout.
- Keep anonymous feedback behavior.
- Separate data processing from UI.
- Prepare architecture for future AI insight generation.
- Keep compatible with FeedbackService from previous task.


Constraints:

- Frontend only.
- No AI integration.
- No machine learning model.
- No database.
- No authentication.
- No API calls.
- No external services.
- No unnecessary dependencies.
- Use mock data only.
- Do not change existing feedback flow.
