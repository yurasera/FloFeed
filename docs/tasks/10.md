Create class-based feedback architecture.

Goal:
Prepare FloFeed to connect learners with the correct class and mentor in the future.

Flow:

Learner:
1. Enter class code
2. Validate class code
3. Start anonymous feedback flow
4. Submit feedback linked to the class

Do not implement backend.

Create:

Data Models:
- Class
- Mentor
- FeedbackSession
- FeedbackResponse

TypeScript interfaces:

Class:
- id
- code
- name
- mentorId

FeedbackSession:
- classId
- selectedMood
- reflectionAnswers
- createdAt


Architecture:

UI
↓
Custom Hooks
↓
Services
↓
Data Models


Requirements:

- Add Join Class step before Welcome.
- Create reusable ClassCodeInput component.
- Create validation logic using mock data.
- Store selected class information in flow state.
- Keep anonymous feedback behavior.
- Prepare interfaces for future Supabase integration.

Constraints:

- Frontend only.
- No database.
- No authentication.
- No API calls.
- No unnecessary dependencies.
- Keep existing feedback flow working.

You can try the flow locally with sample codes like ALPHA01 or BETA02.
