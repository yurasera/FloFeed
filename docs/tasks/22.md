
## 7. Uji koneksi awal

Coba jalankan script berikut di terminal atau dalam file sementara:

```ts
import { supabase } from './src/lib/supabase'

const { data, error } = await supabase.from('mentors').select('*').limit(1)

console.log({ data, error })
```

Jika berhasil, Supabase sudah terhubung dan siap dipakai.
