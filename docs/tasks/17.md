## 2. Siapkan project database

1. Masuk ke dashboard project Supabase.
2. Buka tab SQL Editor.
3. Jalankan script SQL dari file schema yang sudah disiapkan.
4. Pastikan tabel berikut berhasil dibuat:

   - `public.classes`
   - `public.feedback_sessions`
