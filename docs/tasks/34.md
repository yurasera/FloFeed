# Future / V2 - Multi-Card Feedback Session Builder

Create a structured feedback session builder so mentors can compose one feedback session from multiple cards with different input types.

Flow:

1. Mentor creates a feedback session.
2. Mentor adds multiple cards to the session.
3. Each card uses a specific input type.
4. Learner fills the cards in the feedback flow.

Create:

Data Models:
- FeedbackSession
- FeedbackCard
- FeedbackCardType

TypeScript interfaces:

FeedbackSession:
- id
- classId
- title
- description
- isActive

FeedbackCard:
- id
- sessionId
- title
- type
- order
- isRequired

FeedbackCardType:
- mood_check
- rating
- prompt_reflection
- text
- multiple_choice

Requirements:

- Allow one feedback session to contain multiple cards.
- Support different card types in one session.
- Keep the authoring experience simple for mentors.
- Keep the learner flow driven by session card configuration.
- Prepare the structure for richer class-specific feedback formats.

Constraints:

- Future / V2 only.
- Frontend first.
- No AI dependency.
- No backend implementation yet.
